# 创新竞争文献重新分级（2026-10-20）

**研究问题：** 在足端接触/关节行程/执行带宽造成机身补偿能力变化时，预测不同步态的相机扰动及补偿后残余图像运动，并在保持运动任务进度的条件下选择步态。此处的“拟议创新”仍未获得排他性查新证明。

## 判别尺度

- **直接竞争（A）**：优化机载视觉稳定性（或可明确提升视觉性能），且把腿部步态或机身/头部补偿作为可优化的执行变量之一。该级并不等于完全重复。
- **关键方法先例（B）**：控制变量、目标函数或动力学机制中有一项可直接复用/显著限制我们的 claim，但是论文不解决拟议的端到端问题。
- **一般背景/期刊先例（C）**：只是共享平台、方法名称或应用领域；不应用来证明我们的创新被覆盖。

**核心核查项：** (i) 最终视觉质量是否被评价/优化？(ii) 是否优化步态？(iii) 是否结合独立的机身/头部补偿？(iv) 是否预测各候选步态下 *补偿后剩余* 的图像扰动？(v) 是否考虑支撑/驱动/任务进度约束？当中任何一项未报告，只能记为“原文未见”，而不能推断作者一定没做。

## 应立即修正的 Related Work 判断

1. **最直接威胁不能只写 Shaw 2019**：Saggar 2007 把“优化步态以改善机器人视觉效果，同时权衡速度”做得更直接；尤其包含图像中心和旋转项。必须在综述核心位置讨论。
2. **Shaw 不是仅有“注视方向”这么简单**：它明确闭环联动视觉、PCM 和 CPG 的运动指令；我们的差异不能仅仅说“加入相机视觉反馈”。
3. **Smart Gait 不是直接视觉竞争**：它是步态作用于机身扰动的关键机理先例。需要区别“原始反作用/能耗”与“当前可补偿能力下的视觉残余”，但不能凭代价不同自动认定算法创新。
4. **PAMPC/PANTHER/Robic 主要是图像空间评价的公式性先例**，不宜拿它们证明六足步态控制领域的工作已被覆盖。Drones UGV 常规论文主要用于期刊定位。

## 暂时仍有的研究空间

目前未从已核全文中看到：给定状态 `s` 和候选步态 `g`，通过动力学或低维预测器得出其扰动 `d(g,s)`，再对 `g` 依赖的机身补偿可行集合 `C(g,s)` 求最佳可执行补偿，并依据 *补偿后非期望图像运动* 排序选步态：

`g* = argmin_g [ min_{c in C(g,s)} J_img( d(g,s) + c ) ]` （外层还有任务进度、支撑与换步约束）。

**但这仍只是结构性研究空间，不等于新理论成立。** 如果 `C(g,s)` 只是一个常数、`d(g,s)` 用当前步态固定曲线代替所有候选、或比较不优于精调固定步态，那么该方案很容易退化为现成的优化框架换代价。

## 对后续实现的影响

不需要推翻项目。立即把文献矩阵分为“直接问题/方法竞争”和“期刊范式”两页。算法层把计算每个候选步态在当前状态下**最佳可行补偿后的剩余扰动**作为最核心区别，且保持等速、同成本优化和真实成像评估。下一份 Methods 不应写“首次提出视觉反馈调步态”或“首次无云台六足视觉稳定”，也不能仅凭文献相似度较低就写“首次”。
